# AddressDex — Nominatim

Site GitHub Pages autonome pour rechercher des adresses avec Nominatim / OpenStreetMap.

Fonctions :
- recherche manuelle d'adresses et de lieux
- résultats détaillés
- carte interactive Leaflet + OpenStreetMap
- marqueurs pour chaque résultat
- latitude, longitude, type et identifiant OSM
- limitation côté interface à environ une requête par seconde
- aucune autocomplétion

Le service public Nominatim est destiné à un usage raisonnable. Pour un site à fort trafic, utiliser une instance ou un fournisseur Nominatim adapté au volume.
